# みずなら生命 保険申込デモサイト

テスト自動化の練習・デモ用に作った、**架空の生命保険会社の申込サイト**です。
実在の保険会社・商品とは関係ありません。入力内容は保存も送信もされず、ブラウザの中だけで処理されます。

## 申込の流れ

1. **プラン選択**：被保険者の生年月日・性別、保険の種類（定期／医療／終身）、保障額、保険期間、特約、払込方法
2. **契約者情報**：氏名・フリガナ、郵便番号（住所検索）、住所、電話番号、メールアドレス
3. **受取人**：氏名・フリガナ、続柄（「その他」なら理由の入力が必要）
4. **告知**：身長・体重（BMIを表示）、健康状態に関する3つの質問
5. **確認**：入力内容の一覧、同意チェック2つ
6. **完了**：申込番号を表示

画面右側のお見積りパネルは、入力内容に応じて保険料をその場で計算します。

## テストで使えるポイント

- **年齢制限**：被保険者は満20〜70歳。範囲外だとエラーになります。年齢は実行日を基準に計算します。
- **入力チェック**：フリガナは全角カタカナのみ、郵便番号・電話番号の形式、メールアドレスの一致、存在しない日付（2月30日など）を判定します。
- **画面の分岐**
  - 「契約者と保障を受ける方は同じ」をオフにすると、契約者の生年月日・性別と被保険者の入力欄が増えます。
  - 受取人の続柄で「その他」を選ぶと、理由の入力欄が表示されます。
  - 告知の質問1・2で「はい」を選ぶと、詳細の入力欄が表示されます。
  - 告知の質問3で「はい」を選ぶと、申込不可のメッセージが出て先に進めなくなります。
- **体格の注意表示**：BMIが35以上または15未満のとき、注意メッセージが表示されます（先には進めます）。
- **申込番号**：`MZ-年月日-5桁の数字` の形式で、実行のたびに変わります。
- **要素の特定**：主な入力欄とボタンには `data-testid` を付けています。

## v2での変更点（v1との差分）

画面の動作・入力ルールは同じで、文言とロケーターだけを変えています。

| 種類 | v1 | v2 |
|---|---|---|
| ボタン | 契約者情報の入力へ進む／受取人の入力へ進む／告知の入力へ進む | 次へ |
| | 入力内容の確認へ進む | 確認画面へ |
| | この内容で申し込む | 申し込む |
| | 戻る | 前へ |
| | 住所を検索 | 住所自動入力 |
| ラベル | セイ（全角カナ）／メイ（全角カナ） | フリガナ（姓）／フリガナ（名） |
| | メールアドレス（確認用） | メールアドレス（再入力） |
| | 契約者と保障を受ける方は同じ | 契約者本人が保障を受ける |
| 見出し | 契約者情報を入力する | ご契約者さまの情報 |
| ステップ表示 | 契約者情報 | ご契約者 |
| id・data-testid | btn-next-1〜4 | next-plan／next-contractor／next-beneficiary／next-disclosure |
| | btn-submit／btn-zip-search | submit-application／zip-autofill |
| | 契約者欄の `c-`（例：c-last、c-email） | `contractor-`（例：contractor-last、contractor-email） |

## v2-1での変更点（v2との差分）

| 箇所 | v2 | v2-1 |
|---|---|---|
| 見積り・確認画面の保険の種類 | 定期保険 | 定期保険（無解約返戻金型） |
| 完了画面の見出し | お申込みを受け付けました | お申込みが完了しました |
| 申込番号の形式 | MZ-年月日-5桁 | MZL-年月日-5桁 |

プラン選択画面のカード名（定期保険）は変更していません。
